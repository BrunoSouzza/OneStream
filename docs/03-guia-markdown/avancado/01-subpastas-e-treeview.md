# Subpastas Profundas no TreeView

Esta página está localizada em `docs/03-guia-markdown/avancado/01-subpastas-e-treeview.md`, demonstrando como o **TreeView** suporta múltiplos níveis de pastas aninhadas.

## Como Funciona a Expansão Automática

1. Ao acessar diretamente a URL `/03-guia-markdown/avancado/01-subpastas-e-treeview`, todas as pastas pai (`03-guia-markdown` e `avancado`) são abertas automaticamente no menu lateral.
2. Você pode expandir ou recolher pastas individualmente clicando nelas, ou usar os botões **Expandir todas** / **Recolher todas** no topo da barra lateral.
3. A barra de filtro rápido no topo do TreeView permite localizar instantaneamente qualquer arquivo `.md`, mesmo que ele esteja em vários níveis de subpastas.
